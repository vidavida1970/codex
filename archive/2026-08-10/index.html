질문의 범위·긴급성·출처 수·최종 산출물을 기준으로 Search, Deep research, 혼합 방식 중 하나를 선택한다.

핵심 개념 1분

Search는 확인 도구, Deep research는 판단 설계 도구로 구분하면 쉽습니다. 최신 사실이나 특정 원문을 빠르게 찾을 때는 Search, 여러 출처의 맥락·차이·위험을 비교해 보고서로 남길 때는 Deep research가 맞습니다.

SEARCH답이 좁고 시간이 짧을 때최근 공고, 보도자료, 수치 하나, 원문 링크처럼 몇 분 안에 확인할 질문입니다.
DEEP질문이 넓고 판단이 필요할 때여러 출처를 읽고 비교·종합해 전략, 위험, 추천안을 문서화할 질문입니다.
HYBRID먼저 확인하고, 필요할 때 확장Search로 현황과 핵심 원문을 확인한 뒤 복잡성이 증명되면 Deep research로 넘깁니다.

내 업무 적용 포인트

애드아이티는 조사 시작 전에 업무를 빠른 확인·심층 판단·혼합으로 분류하고, Search 결과에서 비교 대상 5곳 이상·상충 근거·전략 추천이 필요해지면 Deep research로 전환합니다.

2분 따라 하기

  1. 오늘 조사할 업무 3개를 적습니다.
  2. 각 업무의 답이 사실·링크인지, 비교·추천인지 표시합니다.
  3. 출처가 3개 이하면 Search, 여러 유형의 다수 출처면 Deep research 후보로 둡니다.
  4. Search 후 심층 전환 조건을 한 줄로 정합니다: “비교 대상 5곳 이상 또는 상충 근거 발견 시 전환.”

복사형 실전 프롬프트

[역할] 너는 공공기관 제안 업무의 조사 라우터다. 지금은 조사를 실행하지 말고 Search, Deep research, Hybrid 중 적합한 방식을 판정하라. [업무] - 조사 질문: [입력] - 사용처와 독자: [제안서/보고/회의] - 필요한 결정: [입력] - 마감 시간: [입력] - 예상 출처: [기관 원문/통계/기사/내부자료] - 산출물: [사실 확인/비교표/전략 보고서] [판정 기준] 1. 답이 특정 사실·원문·최근 정보이고 출처 1~3개면 Search를 우선한다. 2. 여러 출처의 비교·상충 검토·종합·추천이 필요하면 Deep research를 우선한다. 3. 범위를 먼저 확인해야 하면 Search 후 Deep research로 이어지는 Hybrid를 선택한다. 4. 긴급하면 Search로 최소 사실을 먼저 확인하고 심층 조사 필요 여부를 따로 표시한다. [출력] A. 추천 방식: Search / Deep research / Hybrid B. 추천 이유: 범위·시간·출처 수·산출물 기준 4줄 C. Search라면: 검색 질문 3개와 우선 원문 D. Deep research라면: 하위 질문·출처·검증·중단 기준이 있는 계획 E. Hybrid라면: 1단계 Search 완료 기준과 2단계 전환 조건 F. 사람이 확인할 원문과 위험 3개 판정과 계획을 내가 승인하기 전에는 실제 조사를 시작하지 마라.

결과 체크 3문항

  • 답이 단일 사실인지, 여러 근거를 종합한 판단인지 구분했는가?
  • 긴급성·출처 수·최종 산출물이 선택 근거에 반영됐는가?
  • Search 결과에서 Deep research로 넘어갈 전환 조건이 있는가?

자주 하는 실수

  • 깊은 결과가 좋아 보인다는 이유로 모든 질문에 Deep research를 쓰는 것
  • Search의 짧은 요약만 읽고 중요한 의사결정을 확정하는 것
  • Deep research 계획과 사용할 출처를 검토하지 않고 바로 실행하는 것
  • 인용이 있다는 이유만으로 원문 날짜·정의·맥락 확인을 생략하는 것

오늘의 미션

이번 주 조사 업무 5개를 Search·Deep research·Hybrid로 분류하고 이유를 한 줄씩 쓰세요. 그중 Hybrid 1개는 Search 완료 기준과 Deep research 전환 조건까지 정합니다.
