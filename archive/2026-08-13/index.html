100쪽 보고서를 “요약해줘”라고 맡기면, 결론은 남아도 근거 페이지는 사라질 수 있습니다.

오늘의 학습목표
PDF에서 필요한 주장·수치·표·주석을 위치 정보와 함께 추출하고, 원문 육안 확인까지 끝낸 근거표를 만든다.

핵심 개념 1분

PDF 분석의 산출물은 요약문이 아니라 근거지도입니다. 먼저 문서 구조를 훑고, 필요한 주장만 뽑아, 페이지·표·주석 위치를 붙인 뒤 원문을 다시 봅니다.

IDENTIFY문서 식별제목·발행기관·발행일·버전·총 페이지를 확인합니다.
MAP구조 지도목차에서 목적·방법·결과·부록의 범위를 잡습니다.
EXTRACT근거 추출주장·수치·단위·분모·표/그림·주석을 한 행에 묶습니다.
LOCATE위치 고정인쇄 페이지와 PDF 뷰어 페이지가 다르면 둘 다 적습니다.
VERIFY육안 검수표 머리글·각주·단위·예외 조건을 원문 화면에서 재확인합니다.

내 업무 적용 포인트

ChatGPT가 찾은 문장을 바로 쓰지 말고, 한 행 한 근거 원칙으로 파일명·페이지·표/그림·각주를 붙인 뒤 사람이 원문을 확인합니다.

2분 따라 하기

  1. 제안서에 실제 쓸 PDF 1개를 올리고, 제목·기관·발행일·버전·페이지 수를 먼저 묻습니다.
  2. 찾을 주장 1개를 정하고 관련 목차·절·표 번호만 먼저 받습니다.
  3. 주장·수치·단위·분모·측정기간·위치를 한 행으로 추출하게 합니다.
  4. 해당 페이지를 직접 열어 표 머리글과 각주를 확인하고 상태를 ‘확인’으로 바꿉니다.

복사형 실전 프롬프트

[목적] 첨부 PDF에서 [제안서에 사용할 주장/수치]의 근거표를 만든다. [1단계: 문서 확인] - 제목, 발행기관, 발행일, 버전, 총 페이지 - 목차에서 관련 절·표·그림 후보 [2단계: 근거 추출] 다음 열로 표를 작성하라. 파일명 | 주장 요약 | 정확한 수치 | 단위·분모 | 측정기간·대상 | 인쇄 페이지 | PDF 페이지 | 절·표·그림 | 주석·예외 | 검수 상태 [규칙] 1. PDF에 없는 내용은 추측하지 않는다. 2. 정확한 페이지를 찾지 못하면 절·제목을 쓰고 ‘페이지 확인 필요’로 표시한다. 3. 표의 제목, 머리글, 단위, 분모, 각주를 함께 확인한다. 4. 스캔·이미지 기반 표나 복잡한 배치에서 값이 불명확하면 ‘이미지/OCR 재검증’으로 표시한다. 5. 인쇄 페이지와 PDF 뷰어 페이지가 다르면 둘 다 쓴다. 6. 사실 요약과 실무 해석을 별도 열로 분리한다. 7. 마지막에 사람이 원문에서 확인할 항목 3개를 우선순위로 제시한다. 결과 체크 3문항

  • 모든 핵심 수치에 페이지·표/그림·주석 위치가 붙었는가?
  • 단위·분모·기간·대상을 원문에서 확인했는가?
  • 찾지 못한 근거와 스캔/OCR 한계를 숨기지 않았는가?

자주 하는 실수

  • 요약문의 문장을 PDF 원문 인용처럼 사용하는 것
  • PDF 뷰어 페이지와 문서에 인쇄된 페이지를 혼동하는 것
  • 표 본문만 보고 단위·각주·예외 조건을 빼는 것
  • 스캔된 표의 숫자를 원본 확인 없이 복사하는 것
