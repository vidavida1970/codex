내 업무 적용 포인트

파일을 합치기 전에 열 정의표와 조인 대사표를 만들고 미매칭 행을 별도 목록으로 남깁니다.

2분 따라 하기

  1. CSV 1개를 올리고 파일명·기준일·행/열 수·열 이름을 받습니다.
  2. 중복 키·결측·자료형 오류를 건수와 예시 3개씩 확인합니다.
  3. 핵심 지표 1개의 분자·분모·제외 조건을 정의합니다.
  4. 전체 합계와 그룹 합계를 대사하고 차이의 원인 행을 남깁니다.

복사형 실전 프롬프트

[목적] 첨부 표/CSV에서 [검증할 지표]를 재현 가능하게 계산하고 품질 문제를 찾는다. [원본 보호·구조 확인] - 원본은 수정하지 않는다. - 파일명, 기준일, 행 수, 열 수, 열 이름, 자료형을 기록한다. - 한 행의 의미와 기본 키 후보를 설명한다. [품질 검사] - 결측, 중복, 날짜/숫자 형식 오류, 단위 혼합, 범위 밖 값을 건수와 예시로 제시한다. - 0, 빈값, 미수집을 서로 다르게 처리한다. - 여러 표를 합치면 조인 전후 행 수와 미매칭 행을 표시한다. [계산] - 지표의 분자, 분모, 단위, 기간, 대상, 제외 조건을 먼저 쓴다. - 사용한 열, 필터, 공식 또는 코드를 공개한다. - 전체 합계와 그룹 합계를 대사하고 차이를 기록한다. - 행별 비율 평균과 총합 기준 비율을 혼동하지 않는다. [출력] 1. 데이터 프로필 2. 품질 결함표: 결함 | 건수 | 영향 | 처리 제안 3. 수치 검증표: 지표 | 원본 보고값 | 재계산값 | 차이 | 공식 | 판정 4. 제외·미매칭 행 목록 5. 안전한 결론 1문장과 남은 검증 과제 [금지] - 누락값을 임의로 0으로 채우지 않는다. - 확인되지 않은 열 의미를 추측하지 않는다. - 수정 결과를 원본에 덮어쓰지 않는다.

자주 하는 실수

  • 빈값과 0을 같은 값으로 처리하는 것

  • 행별 퍼센트의 평균을 전체 참여율로 쓰는 것
  • 조인되지 않은 행을 조용히 버리는 것
