오늘의 학습목표
앱 연결의 데이터 범위·허용 행동·승인 지점·해제 조건을 한 장으로 정하고, 업무에 필요한 최소 권한만 남긴다.

핵심 개념 1분

연결 가능과 최소 접근은 다릅니다. OpenAI 공식 관리 문서는 App access가 누가 앱을 쓰는지, Action control이 무엇을 할 수 있는지, App permissions가 언제 확인을 요청할지 각각 다룬다고 설명합니다. 연결된 서비스의 기존 사용자 권한도 그대로 적용됩니다.

DATA읽을 데이터 경계허용 폴더·문서·레코드와 제외할 개인정보·비공개 초안을 적습니다.
ACTION허용 행동 경계검색·읽기와 생성·수정·전송·삭제를 분리합니다.
APPROVAL사람이 확인할 지점외부 전송·대량 변경·민감정보 접근 전에는 승인을 요구합니다.
REVOCATION해제와 재검토해제 담당자·검토일·업무 종료 조건을 미리 정합니다.
권한 카드 공식

목적 → 데이터 → 행동 → 승인 → 해제를 한 줄씩 적고, 하나라도 모르면 연결을 보류합니다. 앱 연결은 Memory·개인화·데이터 보관·모델 개선 설정을 대신하지 않습니다.

OpenAI의 앱 접근·행동·확인 3단계 관리

확인 시점2026년 8월 22일, OpenAI 공식 문서문제앱을 켜는 것과 사용자가 실행할 수 있는 행동을 한 설정으로 오해하는 문제업무 흐름관리자가 역할별 App access를 정하고, Action control로 읽기 전용 또는 허용 행동을 제한한 뒤, App permissions로 확인 요청 시점을 설정합니다.확인된 결과사용자·행동·확인 시점을 분리해 관리하는 공식 통제 모델입니다. 고객사의 독립 검증 성과 수치는 공개되지 않았습니다.재현 포인트한 앱·한 승인 폴더·읽기 전용·2인 파일럿으로 시작해 일주일 뒤 접근 로그와 불필요 권한을 검토합니다.

내 업무 적용 포인트

사실: 연결해도 원래 없던 외부 서비스 권한이 새로 생기지는 않습니다. 실무 해석: 잘못 넓게 열려 있던 기존 권한도 함께 따라오므로 사전 정리가 필요합니다. 강사 제안: 첫 연결은 읽기 전용과 승인 폴더 하나로 제한하세요.

2분 따라 하기

  1. 연결하려는 앱 하나와 정확한 업무 목적 하나를 고릅니다.
  2. 읽어도 되는 폴더·문서와 제외할 정보를 각각 한 줄로 씁니다.
  3. 검색·읽기·생성·수정·전송·삭제 중 허용 행동에만 표시합니다.
  4. 승인자·재검토일·연결 해제 조건을 적고 아래 프롬프트로 점검합니다.

복사형 실전 프롬프트

다음 앱 연결안을 최소 권한 원칙으로 검토해줘. [업무 목적] [앱 이름] [데이터 범위: 허용 경로 / 제외 정보] [허용 행동: 검색·읽기·생성·수정·전송·삭제] [금지 행동] [승인 트리거와 승인자] [보관·공유 범위] [재검토일·해제 조건·담당자] 출력: 1. 판정: 연결 가능 / 조건부 가능 / 보류 2. DATA-ACTION-APPROVAL-REVOCATION 표 3. 과도하거나 불명확한 권한 4. 연결 전 반드시 확인할 질문 5. 2인 파일럿 절차와 중단 조건 규칙: - 권한을 추정하지 말 것 - 개인정보·비공개 자료·외부 전송은 별도 위험으로 표시 - 검색·읽기와 쓰기·전송·삭제를 분리 - 확인되지 않은 기능명은 쓰지 말 것

결과 체크 3문항

  • 데이터 범위가 업무상 꼭 필요한 폴더·레코드로 제한됐는가?
  • 읽기와 수정·전송·삭제 권한이 분리됐는가?
  • 승인자·재검토일·해제 조건이 적혀 있는가?

자주 하는 실수

  • 앱 연결을 전체 데이터 접근 허가로 오해하는 것
  • 기존 공유 폴더와 외부 서비스 권한을 점검하지 않는 것
  • 읽기 편의를 위해 쓰기·전송 권한까지 함께 허용하는 것
  • 연결 해제 담당자와 업무 종료 후 처리 기준을 정하지 않는 것

확인된 사실: OpenAI는 Codex 공유 링크가 읽기 전용 스냅샷이며 알려진 비밀 패턴은 가리지만, 민감한 경로·메시지·이미지·diff가 남을 수 있다고 안내했습니다. 개인 링크는 링크를 가진 사람이 열 수 있고, 데이터 설정에서 철회할 수 있습니다.

실무 해석: 앱에서 불러온 맥락이 결과물이나 공유 스냅샷에 포함되는지 게시 전 별도 확인이 필요합니다.

강사 제안: 공유 전 출처·사람 이름·비공개 경로·숨은 필드를 검사하고, 민감정보가 있으면 공유하지 마세요.
