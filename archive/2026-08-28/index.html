DAY 36. 반복 업무를 에이전트 루틴으로 만드는 법

반복 업무는 매번 새로 부탁하는 일이 아니라, 같은 기준으로 다시 실행되는 업무 시스템입니다.

잘 만든 에이전트 루틴은 역할, 입력, 처리 단계, 판단 기준, 산출물, 검수 지점, 기록 방식, 중단 조건을 고정합니다. 그래서 사람마다 달라지는 결과를 줄이고, 팀 업무 기준으로 재사용할 수 있습니다.

오늘의 목표

반복 업무 하나를 Role → Input → Process → Decision rules → Output → Review gate → Memory log → Stop rule 구조의 에이전트 루틴으로 전환합니다.

핵심 개념

ROLE

역할 고정기획자, 검수자, 편집자, 리서처처럼 에이전트가 맡을 책임을 분명히 합니다.

PROCESS

단계 고정읽기, 분류, 판단, 초안, 검수, 기록 순서를 매번 같은 방식으로 수행하게 합니다.

RULES

판단 기준 고정중요도, 출처 신뢰도, 승인 필요 여부, 보류 조건을 기준으로 정합니다.

LOG

기록 고정다음 실행을 위해 읽은 자료, 결정, 보류 항목, 개선점을 남깁니다.

공식 기준으로 보기

OpenAI의 Workspace Agents 안내는 반복 업무를 공유 에이전트로 바꾸고, 연결된 도구 전반에서 워크플로우를 진행하도록 돕는다고 설명합니다. 또한 API 트리거를 통해 내부 시스템이나 예약 작업에서 같은 지침과 연결 맥락으로 에이전트를 실행할 수 있습니다.

ChatGPT Work and Codex 안내는 Work가 한 번 실행, 일정 반복, 트리거 실행, 변경 모니터링으로 진행될 수 있고, 사용자가 진행 확인과 중요 행동 승인을 할 수 있다고 설명합니다. Projects 안내도 파일·지침·채팅을 묶어 반복 워크플로우에 활용할 수 있다고 설명합니다.

루틴 설계표

항목설계 질문예시
Role이 에이전트는 어떤 책임자인가?제안 진행상황 브리핑 매니저
Input매번 어떤 자료를 받아야 하는가?RFP, 회의록, 일정표, 담당자 메모
Process반드시 거칠 단계는 무엇인가?자료 확인 → 이슈 분류 → 위험 표시 → 실행안 작성
Decision rules무엇을 우선 판단할 것인가?마감, 고객 승인, 누락 자료, 외부 발송 여부
Output결과물은 어떤 형식인가?요약 5줄, 리스크 표, 이번 주 할 일
Review gate사람 확인이 필요한 지점은 어디인가?외부 공유, 일정 확정, 고객 회신 문안
Memory log다음 실행을 위해 무엇을 남길 것인가?확정 사항, 보류 항목, 다음 확인일
Stop or ask언제 멈추고 질문해야 하는가?출처 충돌, 권한 부족, 민감 정보 포함

복사형 실전 프롬프트

너는 반복 업무를 에이전트 루틴으로 바꾸는 운영 설계자다. [반복 업무] 업무명: {예: 주간 제안 진행상황 브리핑} 반복 이유: {왜 매번 하는지} 입력 소스: {자료, 링크, 폴더, 앱, 담당자} 판단 기준: {무엇을 중요하게 볼지} 산출물: {보고서, 메일 초안, 카드뉴스 원고, 체크리스트 등} 검수 기준: {사실, 출처, 톤, 누락, 승인 필요 행동} 기록 위치: {Project, 문서, Git, 시트 등} 실행 주기: {매일, 매주, 요청 시, 이벤트 발생 시} 아래 8칸으로 에이전트 루틴 설계표를 작성해줘. 1. Role: 이 에이전트의 역할 2. Input: 매번 받아야 할 자료 3. Process: 반드시 거칠 단계 4. Decision rules: 판단 기준과 우선순위 5. Output format: 결과물 형식 6. Review gate: 사람이 확인할 지점 7. Memory log: 다음 실행을 위해 남길 기록 8. Stop or ask: 멈추거나 질문해야 할 조건 마지막에는 바로 복사해 쓸 수 있는 에이전트 지침 10줄로 정리해줘.

체크리스트

  • 반복 업무의 목적과 사용자가 분명한가?
  • 매번 필요한 입력 자료가 고정되어 있는가?
  • 처리 순서와 판단 기준이 문장으로 적혀 있는가?
  • 산출물 형식이 표, 문단, 체크리스트 등으로 구체적인가?
  • 승인 지점과 멈춤 조건이 분리되어 있는가?
  • 다음 실행을 위한 기록 항목이 남는가?

오늘의 미션

반복 업무 하나를 골라 Role, Input, Process, Decision rules, Output format, Review gate, Memory log, Stop or ask 8칸 루틴표를 만들고, 마지막에 바로 붙여 넣을 수 있는 에이전트 지침 10줄로 정리하세요.

“좋은 에이전트는 일을 대신하는 존재가 아니라, 같은 기준으로 다시 실행되는 업무 습관입니다.”
