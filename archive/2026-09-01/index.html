DAY 38. 팀 협업용 AI 작업 기준 만들기

팀에서 AI를 잘 쓰려면 “각자 알아서”가 아니라 함께 지키는 작업 기준이 필요합니다.

누가 어떤 자료를 넣을 수 있는지, 어떤 결과는 그대로 쓰면 안 되는지, 검수와 승인 기록을 어디에 남길지 정해야 AI가 팀 생산성을 흔들지 않고 받쳐줍니다.

오늘의 목표

팀 AI 사용 기준을 Purpose → Data → Tool → Source → Review → Approval → Log 7칸으로 정리하고, 산출물 검수 책임을 분명히 합니다.

핵심 개념

PURPOSE

목적 기준AI를 쓰는 업무와 쓰지 않을 업무를 구분합니다.

DATA

자료 기준입력 가능한 자료, 제외할 정보, 원문 보관 위치를 정합니다.

REVIEW

검수 기준사실, 수치, 출처, 톤, 저작권, 승인 필요 행동을 확인합니다.

LOG

기록 기준결정, 보류, 수정 이력, 재사용 템플릿을 남깁니다.

공식 기준으로 보기

OpenAI의 ChatGPT Business 데이터·프라이버시 안내는 Business 워크스페이스 데이터가 기본적으로 모델 학습에서 제외되고, 각 사용자의 채팅과 Codex 기록은 다른 구성원에게 자동으로 보이지 않는다고 설명합니다.

관리형 ChatGPT 계정의 데이터 접근 안내와 ChatGPT Enterprise 안내는 조직 계정에서 관리자 권한, 멤버 관리, 보안·관리 기능이 중요하다는 점을 보여줍니다. 팀 기준은 기술 설정과 업무 습관을 함께 다뤄야 합니다.

실무 설계표

항목기준작성 포인트
PurposeAI 사용 목적초안, 요약, 검수, 아이디어, 자동화 중 어디에 쓰는가
Data입력 가능 자료공개자료, 내부자료, 민감정보 제외 기준을 구분한다
Tool사용 도구Chat, Work, Project, 앱 연결, GitHub 등 사용 범위를 정한다
Source출처 표기링크, 파일명, 날짜, 페이지, 확인자를 남긴다
Review검수 책임사실, 수치, 톤, 법무·고객 승인 필요 여부를 본다
Approval승인 행동외부 발송, 삭제, 권한 변경, 공개 업로드는 사람 승인을 둔다
Log기록 위치Project 지침, 회의록, README, 체크리스트로 남긴다

복사형 실전 프롬프트

너는 팀 AI 작업 기준을 만드는 운영 책임자다. [팀 정보] 팀/프로젝트명: {입력} 주요 업무: {제안, SNS, 보고, 디자인, 고객 응대 등} AI 사용 목적: {초안, 분석, 검수, 자동화, 발표 준비} 사용 도구: {ChatGPT, Work, Project, GitHub, Drive, 앱 연결 등} 입력 자료 범위: {허용 자료와 제외 자료} 검수 책임자: {담당자 또는 역할} 승인 필요 행동: {외부 발송, 공개 업로드, 삭제, 권한 변경 등} 아래 7칸으로 팀 AI 작업 기준표를 작성해줘. 1. Purpose: AI를 쓰는 목적과 금지할 사용 2. Data: 입력 가능한 자료와 제외할 정보 3. Tool: 사용할 도구와 연결 앱 범위 4. Source: 출처 표기 방식 5. Review: 검수 항목과 책임자 6. Approval: 사람 승인이 필요한 행동 7. Log: 기록 위치와 보존 방식 마지막에는 팀원이 바로 읽을 수 있는 AI 작업 원칙 10줄로 정리해줘.

체크리스트

  • AI 사용 목적과 금지할 사용이 분리되어 있는가?
  • 입력 가능한 자료와 제외할 정보가 구체적인가?
  • 출처 표기 방식에 링크, 날짜, 파일명, 페이지가 포함되는가?
  • 검수 항목과 책임자가 산출물별로 지정되어 있는가?
  • 외부 발송, 공개 업로드, 삭제, 권한 변경에 승인 지점이 있는가?
  • 수정 이력과 재사용 기준을 남길 위치가 정해져 있는가?

오늘의 미션

우리 팀 업무 하나를 기준으로 Purpose, Data, Tool, Source, Review, Approval, Log 7칸 AI 작업 기준표를 만들고, 팀원이 지켜야 할 원칙 10줄을 작성하세요.

“팀의 AI 실력은 멋진 프롬프트보다 같은 기준으로 검수하고 기록하는 습관에서 자랍니다.”
