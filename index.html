오늘의 학습목표
승인된 프롬프트 하나를 고정 규칙·변수·테스트·운영 정보로 분리해 팀이 다시 쓸 수 있는 업무 템플릿 v1.0으로 만든다.

핵심 개념 1분

템플릿은 긴 프롬프트 저장본이 아닙니다. 바뀌지 않을 품질 기준과 매번 바뀌는 입력값을 분리한 업무 표준입니다.

고정목적·대상·근거·형식·금지 규칙결과가 달라져도 반드시 지켜야 할 기준을 잠급니다.
변수[기관명] [사업명] [대상] [자료] [분량]매번 달라지는 값은 대괄호 필드로 만들고 필수 여부를 표시합니다.
시험정상·예외·누락 입력서로 다른 실제 입력 세 개로 실행해 같은 품질 기준을 재현하는지 봅니다.
운영담당자·버전·수정일누가 언제 왜 바꿨는지 남겨야 팀의 표준이 됩니다.

BETTER

고정값과 변수 분리

승인 기준은 고정하고 바뀌는 값은 필드화합니다. 필수 입력이 없으면 작성하지 말고 누락 목록부터 요청하게 합니다.

애드아이티 실무 예시 · 공공기관 보도자료 템플릿

고정: 공식 명칭 사용, 제공 자료만 사실로 확정, 제목 30자 이내, 인용문 임의 생성 금지, 마지막에 사실·수치 검수표.

변수: [기관명] [사업명] [발표일] [핵심 대상] [근거 자료] [담당 부서] [CTA].

빈값 규칙: 근거 자료나 담당 부서가 없으면 본문을 쓰지 않고 누락 입력만 표로 요청.

해외 기업 · 업체 제공 사례

Moderna: 반복 기준을 공유 GPT 업무 흐름으로 전환

적용 시점2024년 공개, ChatGPT Enterprise 도입 초기 2개월 기준 문제전문 업무의 반복 기준과 자료 탐색 방식을 여러 팀이 일관되게 적용해야 했음 업무 흐름업무별 지시·참고 지식·산출물 기준을 GPT로 구성하고, 실제 사용자가 반복 작업에 적용 공개 결과2개월 안에 750개 GPT가 만들어졌고, 주간 활성 사용자의 40%가 GPT를 제작했으며 사용자당 주 120회 대화를 기록. 이는 도입·활동 지표이며 품질 향상 수치는 아님 예시Dose ID는 표준 선량 선택 기준에 따라 분석 근거·출처·차트를 제공하고 임상팀 판단을 보조 재현 포인트한 사용자·한 업무·한 출력부터 좁게 만들고, 실제 예시 입력으로 테스트한 뒤 공유

사실과 해석 구분

확인된 사실: 공개된 도입·활동 지표와 Dose ID 흐름. 강사 해석: 이 사례의 재현 포인트는 GPT 개수보다 반복 기준을 명시적 업무 자산으로 바꾼 데 있습니다. 국내에서 같은 지표로 검증된 공개 사례는 확인하지 못해 꾸며 넣지 않았습니다.

2분 따라 하기

  1. 최근 승인된 결과물과 당시 프롬프트를 하나 고릅니다.
  2. 기관명·날짜·대상처럼 바뀌는 값을 [대괄호]로 바꿉니다.
  3. 승인 이유였던 문체·근거·형식·금지 규칙은 고정합니다.
  4. 필수값 하나를 비운 입력까지 포함해 세 번 시험하고 실패를 기록합니다.

결과 체크 3문항

  • 매번 바뀌는 정보가 모두 변수 필드로 분리됐는가?
  • 누락·충돌 입력에서 멈추는 규칙과 검수 기준이 있는가?
  • 서로 다른 세 입력으로 시험하고 담당자·버전을 기록했는가?

자주 하는 실수

  • 모든 문장을 변수로 만들어 품질 기준까지 흔들리게 하는 것
  • 모든 값을 고정해 다른 기관·사업에 재사용하지 못하는 것
  • 한 번 성공한 결과만 보고 팀 표준으로 배포하는 것
  • 담당자·버전·변경 이유 없이 여러 복사본을 만드는 것
