# DAY 28. 표·CSV에서 수치를 검증하는 법

- 발행일: 2026년 8월 14일
- 과정: ADDIT | ChatGPT로 성공하기 (28/40)
- 핵심 한 문장: 숫자를 믿기 전에, 그 숫자를 만든 행과 분모를 검증하세요.

## 10초 훅
합계가 맞아 보여도 중복 행 하나와 잘못된 분모 하나가 전략 전체를 바꿀 수 있습니다.

## 오늘의 학습목표
표·CSV의 구조와 품질을 먼저 검사하고, 핵심 수치를 원자료 합계와 대조해 재현 가능한 검증표를 만든다.

## 핵심 개념 1분
분석보다 먼저 데이터 계약을 확인합니다. PROFILE(구조) → CLEAN(결측·중복·형식·단위) → DEFINE(분자·분모·제외 조건) → RECON(전체·그룹 합계 대사) → REPLAY(열·필터·공식·코드 보존) 순서로 검증합니다.

## 잘못된 사용법과 개선
- 잘못: “성과가 좋은 채널을 찾아줘”라고만 요청하고 누락·중복·기간·비용 포함 여부를 확인하지 않는다.
- 개선: 행·열 프로필과 결함 목록을 먼저 받고, 수정 규칙을 승인한 뒤 동일한 공식으로 합계를 재계산한다.

## 애드아이티 실무 사례
공공기관 SNS 성과 CSV라면 게시물 ID 중복, 도달 0과 미수집, 유료·자연 도달 혼합, 참여율 계산 오류를 먼저 검사합니다. 참여율은 행별 비율 평균이 아니라 총 참여÷총 도달로 재계산하고 결론 문장에 분모와 제외 조건을 씁니다.

## 오늘의 실제 사례
**Virgin Atlantic · 업체 제공 사례 · 2026.08.10**
- 문제: 고객 여정 정보가 여러 대시보드·업무공간·보고 도구에 흩어져 비교가 어려웠다.
- 흐름: ChatGPT Work로 비교 기준을 구조화하고 조사 결과를 검토용 데이터셋으로 정리했으며, 여러 데이터셋은 ChatGPT Sites의 공통 화면으로 연결했다.
- 결과: 회사 담당자에 따르면 수주 걸리던 경쟁사 조사를 수시간으로 단축했고 결과는 5개년 디지털 전략의 투자 권고에 반영됐다. 독립 측정이 아닌 당사자 제공 결과다.
- 재현 포인트: 표를 합치기 전에 열 정의·조인 키·누락 행·출처 시점을 고정하고 사람이 검토한다.
- 원문: https://openai.com/index/virgin-atlantic/chatgpt-work/

### 내 업무 적용 포인트
파일을 합치기 전에 열 정의표와 조인 대사표를 만들고 미매칭 행을 별도 목록으로 남깁니다.

## 2분 따라 하기
1. CSV의 파일명·기준일·행/열 수·열 이름을 받습니다.
2. 중복 키·결측·자료형 오류를 건수와 예시 3개씩 확인합니다.
3. 핵심 지표 1개의 분자·분모·제외 조건을 정의합니다.
4. 전체 합계와 그룹 합계를 대사하고 차이의 원인 행을 남깁니다.

## 복사형 실전 프롬프트
```text
[목적] 첨부 표/CSV에서 [검증할 지표]를 재현 가능하게 계산하고 품질 문제를 찾는다.

[원본 보호·구조]
- 원본은 수정하지 않는다.
- 파일명, 기준일, 행 수, 열 수, 열 이름, 자료형, 한 행의 의미와 기본 키 후보를 기록한다.

[품질 검사]
- 결측, 중복, 날짜/숫자 형식 오류, 단위 혼합, 범위 밖 값을 건수와 예시로 제시한다.
- 0, 빈값, 미수집을 서로 다르게 처리한다.
- 여러 표를 합치면 조인 전후 행 수와 미매칭 행을 표시한다.

[계산]
- 지표의 분자, 분모, 단위, 기간, 대상, 제외 조건을 먼저 쓴다.
- 사용한 열, 필터, 공식 또는 코드를 공개한다.
- 전체 합계와 그룹 합계를 대사하고 차이를 기록한다.
- 행별 비율 평균과 총합 기준 비율을 혼동하지 않는다.

[출력]
1. 데이터 프로필
2. 품질 결함표: 결함 | 건수 | 영향 | 처리 제안
3. 수치 검증표: 지표 | 원본 보고값 | 재계산값 | 차이 | 공식 | 판정
4. 제외·미매칭 행 목록
5. 안전한 결론 1문장과 남은 검증 과제

[금지]
- 누락값을 임의로 0으로 채우지 않는다.
- 확인되지 않은 열 의미를 추측하지 않는다.
- 수정 결과를 원본에 덮어쓰지 않는다.
```

## 결과 체크 3문항
1. 원본 행 수와 분석 행 수의 차이를 설명했는가?
2. 핵심 비율의 분자·분모·제외 조건이 명확한가?
3. 같은 파일과 공식으로 다시 계산할 수 있는가?

## 자주 하는 실수
빈값과 0을 같은 값으로 처리, 중복 제거 전후 합계 차이 미기록, 행별 퍼센트 평균을 전체 참여율로 사용, 조인되지 않은 행을 조용히 폐기.

## 오늘의 미션
실제 업무 CSV 1개에서 행 수·결측·중복·핵심 지표 공식·전체/그룹 합계 대사를 확인하고, 결함 1개와 수정 전후 수치 차이를 기록합니다.
