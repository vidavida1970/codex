# DAY 33 — 앱 연결 전 데이터 경계와 권한 점검하기

- 발행일: 2026년 8월 22일
- 과정: ADDIT | ChatGPT로 성공하기
- 레벨: LEVEL 4 — Projects·메모리·앱 연결·Work·Codex·SOP·통합 프로젝트
- 핵심 한 문장: 연결 가능과 업무에 필요한 최소 접근은 다릅니다.

## 10초 훅

앱 연결의 질문은 “연결할 수 있나?”가 아니라 “무엇을 읽고, 무엇을 실행하며, 누가 승인하고, 어떻게 끊을 것인가?”입니다.

## 학습 목표

- 앱 연결 전 데이터 범위와 행동 권한을 구분한다.
- 승인 지점과 연결 해제 절차를 업무 승인표로 만든다.
- 공개·내부·민감 자료가 섞이지 않도록 최소 접근 원칙을 적용한다.

## 핵심 개념: DATA · ACTION · APPROVAL · REVOCATION

1. **DATA** — 필요한 폴더·파일·기간·계정만 읽도록 범위를 좁힌다.
2. **ACTION** — 검색·요약 같은 읽기와 생성·수정·전송 같은 쓰기를 분리한다.
3. **APPROVAL** — 외부 전송, 게시, 삭제 등 영향이 큰 행동에는 사람의 확인 지점을 둔다.
4. **REVOCATION** — 담당자 변경·사업 종료·오연결 시 즉시 끊는 담당자와 절차를 정한다.

## 잘못된 사용법과 개선

- 잘못: “드라이브 전체를 연결하고 제안서를 알아서 완성해.”
- 개선: “공개 입찰 폴더의 최근 90일 자료만 검색·요약해. 파일 수정·공유·삭제는 하지 말고, 외부 전송 전에는 내 승인을 요청해.”

## 애드아이티 업무 적용

| 업무 | 필요한 데이터 | 허용 행동 | 승인 지점 |
|---|---|---|---|
| 마케팅 | 승인된 캠페인 자료 | 검색·요약 | 외부 게시 전 |
| 홍보 | 공개 보도자료·언론목록 | 초안 작성 | 발송 전 |
| 공공기관 제안 | RFP·공개 통계·내부 템플릿 | 근거 추출·초안 | 민감자료 사용·제출 전 |

## 오늘의 실제 사례

공개된 독립 고객 성과 수치를 검증할 수 없어, OpenAI의 공식 앱 관리 워크플로를 공개 재현 사례로 사용했습니다. 관리자는 연결 가능 앱과 작업을 제어하고, 사용자는 허용된 범위 안에서 앱을 연결합니다. 재현 포인트는 **업무 목적 → 최소 데이터 → 읽기/쓰기 구분 → 고위험 행동 승인 → 연결 해제 담당자** 순서로 승인표를 작성하는 것입니다.

- [Apps and connectors — ChatGPT Enterprise Learning](https://learn.chatgpt.com/docs/enterprise/apps-and-connectors)
- [Security and privacy — OpenAI Developers](https://developers.openai.com/plugins/guides/security-privacy)
- [OpenAI Academy: Connectors](https://academy.openai.com/public/clubs/work-users-ynjqu/resources/connectors)

## 내 업무 적용 포인트

공공기관 제안 업무에서는 자료 검색과 초안 작성까지는 허용하되, 민감자료 포함·외부 공유·최종 제출은 사람의 승인을 남깁니다.

## 2분 따라 하기

1. 연결하려는 앱 하나와 업무 목적 한 줄을 적습니다.
2. 필요한 데이터만 폴더·기간·소유자로 좁힙니다.
3. 검색·요약·생성·수정·전송 중 허용 행동을 표시합니다.
4. 외부 영향이 있는 행동의 승인자를 적습니다.
5. 연결 해제 담당자와 종료 조건을 적습니다.

3) 사람 승인이 필요한 행동
4) 연결 해제 조건·담당자
5) 과도한 권한 또는 미확인 위험
확인되지 않은 기능은 추정하지 말고 ‘관리자 확인 필요’로 표시하라.

## 결과 체크 3문항

- 필요한 데이터 범위가 폴더·기간·소유자 수준으로 좁혀졌는가?
- 읽기와 쓰기 행동, 사람의 승인 지점이 구분됐는가?
- 연결 해제 조건과 담당자가 기록됐는가?

## 자주 하는 실수

- 앱 이름만 보고 실제 데이터 범위와 작업 권한을 확인하지 않는다.
- 검색·요약과 수정·전송을 같은 권한으로 취급한다.
- 사업 종료나 담당자 변경 시 연결 해제를 기록하지 않는다.
