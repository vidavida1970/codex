# DAY 36 — 반복 업무를 에이전트 루틴으로 만드는 법

발행일: 2026년 8월 28일

## 핵심

반복 업무는 매번 새 프롬프트로 처리하지 말고 Role, Input, Process, Decision rules, Output, Review gate, Memory log, Stop rule이 고정된 에이전트 루틴으로 바꿔야 합니다. 루틴이 생기면 품질 편차가 줄고, 다음 사람이 이어받아도 같은 기준으로 일할 수 있습니다.

## 공식 근거

- OpenAI Help Center, ChatGPT Workspace Agents for Enterprise and Business: Workspace Agents는 반복 업무를 공유 에이전트로 바꾸고, 연결된 도구 전반에서 워크플로우를 앞으로 진행하도록 돕습니다.
- OpenAI Help Center, ChatGPT Work and Codex: Work는 한 번 실행, 일정 반복, 트리거 실행, 변경 모니터링으로 진행될 수 있고, 사용자는 진행 확인·방향 변경·중요 행동 승인을 할 수 있습니다.
- OpenAI Help Center, Projects in ChatGPT: Projects는 파일, 지침, 채팅을 한 곳에 모아 반복 워크플로우와 장기 작업에 활용할 수 있습니다.
- OpenAI Help Center, Skills in ChatGPT: Skills는 특정 작업을 더 일관되게 수행하도록 지침, 예시, 코드를 포함할 수 있는 재사용 가능한 워크플로우입니다.

## 5분 강의 원고

반복 업무는 단순히 자주 하는 일이 아닙니다. 같은 목적, 같은 입력, 같은 판단 기준, 같은 결과물 형식이 반복되는 일입니다.

예를 들어 “이번 주 제안 진행상황 정리해줘”라는 요청은 한 번은 처리할 수 있습니다. 하지만 매주 같은 품질로 만들려면 요청문만으로는 부족합니다. 어떤 자료를 읽을지, 어떤 기준으로 위험을 판단할지, 어떤 표로 정리할지, 사람 확인이 필요한 부분은 어디인지가 고정되어야 합니다.

DAY 36의 핵심은 반복 업무를 8칸 루틴으로 바꾸는 것입니다.

1. Role: 이 에이전트가 맡는 역할
2. Input: 매번 필요한 자료
3. Process: 반드시 거칠 단계
4. Decision rules: 판단 기준과 우선순위
5. Output format: 결과물 형식
6. Review gate: 사람이 확인할 지점
7. Memory log: 다음 실행을 위해 남길 기록
8. Stop or ask: 멈추거나 질문해야 할 조건

이 8칸이 있으면 “매번 잘 부탁해”가 아니라 “항상 이 방식으로 일해줘”가 됩니다. 특히 제안서, SNS 운영, 카드뉴스 원고, 주간 보고, 회의 후속 정리처럼 반복되는 지식업무는 에이전트 루틴으로 바꾸는 순간 속도보다 안정성이 먼저 좋아집니다.

## 오늘의 미션

반복 업무 하나를 골라 Role, Input, Process, Decision rules, Output format, Review gate, Memory log, Stop or ask 8칸 루틴표를 만들고, 마지막에 바로 붙여 넣을 수 있는 에이전트 지침 10줄로 정리하세요.
